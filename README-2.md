ResearchConnect – VJTI starter dataset

Source: https://vjti.ac.in/faculty-research-publications/

Contents:
- faculty.csv: 12 names and departments listed on the official VJTI faculty publications page.
- papers.csv: 19 selected publication records transcribed from that page.
- authorship.csv: links the VJTI faculty author to each selected paper.

Important:
1. This is a starter sample, not a complete VJTI faculty or publication database.
2. Verify all records against the source page before final submission; the page can change.
3. Expertise is intentionally blank; populate it only after checking official faculty profiles.
4. External coauthors are omitted from authorship.csv, so this file only represents VJTI faculty-to-paper links.
5. Empty DOI means the extracted official listing did not provide one.
6. Paper IDs in authorship.csv match paper IDs in papers.csv.
7. Do not invent collaboration edges. Add an edge only when two VJTI faculty are both verified authors of the same paper.
